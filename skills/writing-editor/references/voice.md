# Personal Voice

这是稳定 Voice 的初始版本。后续应由真实编辑行为持续校准。

## Stable Seed

- 结论优先。
- 信息密度高；能一句说清楚，不扩成三句。
- 技术表达直接，允许专业术语，但不要为了显得专业而堆抽象名词。
- 比起“面面俱到”，更重视明确判断和取舍。
- 能具体就不抽象。
- 少官话、少拔高、少总结性废话。
- 可以有适度口语感，但不故意制造随意或错误。
- 不改变原始事实、数据、观点和语气意图。

## Preferred Shape

通常优先：

```text
结论
→ 原因
→ 关键事实 / 例子
→ 必要时给建议或下一步
```

不默认采用：

```text
宏观背景
→ 第一第二第三
→ 价值升华
→ 再总结一次
```

## Avoid by Default

- 值得注意的是
- 综上所述
- 不难发现
- 显著提升
- 有效赋能
- 形成闭环
- 持续沉淀
- 全方位
- 系统性地

这些词不是禁用词；只有在表达准确且必要时才保留。
